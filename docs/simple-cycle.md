# 우선 한 사이클만 테스트

이 버전의 목표는 ‘사진 여러 장 → OCR 후보 확인/수정 → 한 번에 저장 → 내 장소 확인’입니다.
API 설정, 후보별 지도 검색, 회원가입 없이 진행합니다. 실제 장소를 공식 확인하는 기능은 아닙니다.

1. 브라우저에서 사진/스크린샷 여러 장을 선택합니다.
2. 결과를 내려보며 이름/주소의 OCR 오타를 수정합니다.
3. ‘확인한 장소 한 번에 담기’에서 ‘저장할 이름과 주소를 확인했어요’를 켭니다.
4. ‘한 번에 저장(N곳)’을 누릅니다. 주소를 못 읽어도 이름이 있으면 미확인 상태로 저장합니다. 이름이 없거나 공식 지점 선택이 필요한 후보는 확인이 필요하다고 표시합니다.
5. 내 장소에서 목록을 확인하고 새로고침해도 유지되는지 봅니다.
6. 같은 후보를 다시 저장해도 중복이 늘지 않아야 합니다.

확인 후 저장한 OCR 데이터는 unverified로 유지됩니다. 지도 앱 즐겨찾기를 수정하지 않습니다.
네이버/카카오 후보 검색 버튼은 ‘검색 단서 보기’ 안으로 접었습니다. 기본 테스트에서 누를 필요가 없습니다.
기존 개별 저장과 지도 검색 설정은 유지합니다.

이 사이클에는 API 키나 유료 AI가 필요 없습니다. 정확한 공식 상호/지점 확인을 자동으로 하려면
다음 단계에서 카카오 REST 키와 검색 서버를 연결해야 합니다. 사진 OCR 정확도 자체는 별도 과제입니다.

검증: 이름이 있는 후보는 주소가 없어도 일괄 저장, 사용자 수정 반영, 애매한 공식 지점 자동 선택 금지,
저장 전 확인 스위치, 새로고침 복원, 반복 저장 중복 방지를 테스트합니다.

사진별 성공·실패·후보 없음·중복 상태를 모두 표시합니다. 분석하지 못한 사진은 ‘장소 직접 보완’으로 이름을 입력할 수 있습니다. 읽지 못한 상호·주소를 자동으로 만들어 넣지 않습니다.
주소 없는 같은 이름을 서로 다른 사진에서 읽었으면 임의로 합치지 않습니다. 웹에서 동일한 사진·동일 이름을 재저장한 경우는 중복을 방지합니다. 네이티브에서 재선택한 사진의 파일 URI가 달라지면 동일 사진 판별은 별도 보완이 필요합니다.
