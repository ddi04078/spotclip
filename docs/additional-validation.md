# 추가 검증: 가능한 미실행 항목

이번에는 앱·OCR 코드를 수정하지 않고 테스트만 추가했습니다.
Chromium에서 신규 7개 테스트와 TypeScript 검사가 통과했습니다.

| 검증 | 결과 | 범위/제한 |
|---|---|---|
| 터치 시작·이동·종료로 마지막 결과 이동 | 통과 | Chromium 모바일 에뮬레이션/CDP. 실물 iPhone 아님 |
| 입력칸 포커스 후 화면 높이 480px로 축소·수정·저장 | 통과 | 소프트웨어 키보드를 가정한 viewport 축소. 실제 iOS 키보드 아님 |
| CSS zoom 200%에서 마지막 결과·하단 탭 접근 | 통과 | CSS 확대. 실제 브라우저 메뉴 배율 설정과 다름 |
| 손상 PNG | 통과 | 오류 안내, 결과/저장 없음 |
| OCR worker 파일 HTTP503 | 통과 | 오류 안내, Mock 대체/저장/유료 API 호출 없음 |
| 빈 이미지 | 통과 | 실제 OCR 실행 후 후보0, 저장0 |
| 흐린 SNS UI 문구 이미지 | 통과 | 실제 OCR 실행 후 후보0, 저장0. 흐린 장소 상호의 정확도를 입증하지 않음 |

처음 터치 테스트는 Input.synthesizeScrollGesture 명령으로 실패했습니다.
진단에서 이 명령이 실제 scrollTop을 바꾸지 않는 것을 확인했습니다.
같은 화면에 Input.dispatchTouchEvent의 touchStart/move/end를 전달하자 scrollTop이
41→1275(최하단)로 변했습니다. 앱을 수정하지 않고 테스트 입력 방법을 수정한 뒤
마지막 버튼과 하단 탭이 viewport 안에 들어오는지 다시 검사했습니다.

배포 브랜치 raw 파일 검증: index.html과 OCR assets 9개 모두 HTTP200,
SHA256이 로컬에서 테스트한 파일과 일치했습니다.
이는 GitHub Pages 런타임 검증이 아닙니다. 공개 github.io URL은 tunnel403으로 차단되었습니다.

Firefox와 WebKit 엔진 설치를 각각 시도했으나 다운로드 도메인이403으로 차단되어
해당 엔진 테스트는 실행하지 못했습니다. 앱 결함이나 테스트 통과로 분류하지 않습니다.

사용자 원본 사진은 /workspace/attachments 등에 실행 가능한 이미지 파일로 존재하지 않았습니다.
채팅 사진을 원본 픽셀로 OCR에 넣은 테스트는 여전히 미실행입니다.
실물 iPhone/Android, Xcode/Apple Vision 네이티브 컴파일, 실물 키보드,
실제 브라우저 메뉴 200% 확대, 실제 API 호출은 이 검증에 포함되지 않습니다.
특수한 글꼴의 한글 인식(세 번째 상호)은 여전히 불완전합니다.
