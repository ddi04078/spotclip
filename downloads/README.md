# SpotClip PC 체험판

[PC 체험 ZIP 다운로드](./SpotClip-PC-Test.zip?raw=true)

1. Node.js LTS를 설치하세요: https://nodejs.org/
2. ZIP을 완전히 압축 해제하세요.
3. Windows는 `start-pc.bat`를 더블클릭하세요. Mac은 `start-pc.command`를 실행하세요.
4. 브라우저의 사진 버튼으로 PC 사진을 선택하세요. 실행한 터미널은 열어두세요.

미리 빌드되어 있어 npm install과 Expo Go는 필요하지 않습니다.
현재 사진 분석과 장소 확인은 Mock이며, 저장·목록·지도 링크를 체험할 수 있습니다.
사진과 장소는 해당 브라우저에 보관되며 모바일 앱과 동기화하지 않습니다.
